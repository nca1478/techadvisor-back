# Política de privacidad

## Datos que tratamos

Tratamos los datos necesarios para la compra: correo electrónico, nombre,
dirección de envío y el historial de pedidos.

## Datos que nunca compartimos con el asistente

El asistente de compras **nunca recibe** tu correo, dirección, documento de
identidad ni datos de pago. Solo recibe tu pregunta, los datos del catálogo y
los fragmentos de documentos recuperados.

## Tus derechos

Puedes solicitar el acceso, rectificación o eliminación de tus datos
contactando con el equipo humano de soporte. Las conversaciones con el
asistente se conservan únicamente para dar continuidad al asesoramiento.
